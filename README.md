# Exercício 1174 - Seleção em Vetor I

## Descrição

Programa desenvolvido em Java que lê 100 números reais e os armazena em um vetor. Ao final, exibe os valores menores ou iguais a 10, junto com suas posições no vetor.

## Tecnologias utilizadas

- Java
- Apache NetBeans IDE
- Maven

## Entrada

O programa lê 100 números reais, um por linha.

## Saída

Para cada valor menor ou igual a 10, exibe uma linha no formato `A[i] = valor`, com o índice de 0 a 99 e o valor apresentado com uma casa decimal.
